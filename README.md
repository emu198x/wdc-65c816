# wdc-65c816

The WDC 65C816 CPU, cycle-stepped, with a pin-level bus interface.

| Crate | Registry |
|---|---|
| [`emu198x-wdc-65c816`](crates/emu198x-wdc-65c816) | [crates.io](https://crates.io/crates/emu198x-wdc-65c816) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the SNES and the C64's SuperCPU.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
